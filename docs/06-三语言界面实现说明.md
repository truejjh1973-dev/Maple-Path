# 三语言界面实现说明

日期：2026-10-24。

- 已支持简体中文（zh-Hans）、繁體中文（zh-Hant）、English（en）。
- 公共导航与学生页顶部均有语言选择器，偏好保存在当前浏览器，刷新和路由切换后保留。
- 覆盖公开首页、学校目录、示例、登录说明、学生档案、问卷、课程、专业、模拟和报告；包括按钮、表单选项、验证信息、确认弹窗、占位文字、无障碍标签和文档标题。
- 官方课程名和装饰性英文标题保持英文；用户输入和JSON导出不自动翻译。
- 下拉选项先固定原始value再翻译标签，不改变已存身份、课程状态或规则计算。语言切换不重绘表单，避免丢失正在输入的内容。
- 繁体学校关键词会归一化，可搜索“滑鐵盧”等名称。
- 434条维护词条，全部打包本地，无运行时翻译API或CDN依赖。维护方式见locales/README.md。

## 实际检查

- 11项Node测试通过，包括翻译覆盖、目录一致性、动态数字/课程名及原有导航业务。
- 浏览器检查11个路由的英文标题、段落、表单与消息，未发现未翻译中文（语言选择器除外）。
- 实际确认繁体界面、繁体搜索、刷新记忆和课程选项原始值保留。
- 调整窄屏英文导航；未执行所有设备的固定尺寸矩阵测试。
- 当前仍是本地原型，新增多语言不表示已实现云端注册或AI。
