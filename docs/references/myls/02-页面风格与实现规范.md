# 视觉观察与页面实现参考

## 1. 真实观察与建议的区别

本文件前半部分记录MYLS当前桌面页面；后半部分是为MaplePath制定的设计建议。移动端断点、组件尺寸、绿色情调不是MYLS实测值。

原站真实特征：暖白背景，黑色粗体大标题，关键短句以鲜蓝色强调；主体使用无衬线字体；主按钮为蓝底白字胶囊。内容围绕一项任务组织，配大留白与轻边框白卡片。

此前MaplePath森林绿方案是自主品牌方向，不能写成MYLS原站配色。

## 3. 首页桌面结构

截图：01-home-desktop.png。

```text
┌ Logo ─ 产品/目录/价格/资源 ─────── 语言 登录 [主CTA] ┐
│                                                    │
│ 大标题（黑色）              产品演示卡               │
│ 结果短句（蓝色）            ┌ 浏览器式卡片头 ─────┐ │
│                            │ 五个报告标签         │ │
│ 两到三行解释                │                     │ │
│ 三条勾选式价值说明           │ 输入或报告内容       │ │
│                            │                     │ │
│ [主CTA →]                  └─────────────────────┘ │
│ 小号信任/试用说明                                   │
└────────────────────────────────────────────────────┘
  类别入口 → 三步流程 → 证明材料 → 套餐 → FAQ → 最后CTA
```

观察：首屏左右接近均分；演示不是普通装饰图，而是让用户预先理解输出；顶部导航轻薄，标题下的空白与层级非常清晰。右卡具有圆角、浅边框、柔和阴影，内部标签使用浅灰底轨道与白色选中项。

MaplePath改编：
- 左标题：“从BC课堂，找到你的大学方向。”
- 强调句：“看见差距，知道下一步。”
- 副文案：“结合兴趣、课程成绩与个人经历，探索加拿大本科专业与申请路径。”
- 三条价值：八校路径探索、分开理解兴趣与条件、比较当前与改善方案。
- 主CTA“开始我的规划”，次CTA“免费探索学校”。
- 右侧替换为虚构学生报告演示，不使用竞品视频。
- 首页下面不做收费套餐，替换为“免费学校探索 / 注册后的个人规划”服务说明。
- 没有真实用户反馈时不放伪造评价、头像、成功率或录取通知。

## 4. 目录页面结构

截图：02-programs-desktop.png。

原站观察：左对齐大标题与说明；搜索框在下方，结果数量紧随；再下面是一行带数量的胶囊筛选；当前分类用深色底；卡片桌面四列，图片在上，名称和机构在下；整体无重型侧边栏。

MaplePath学校目录建议：

```text
探索加拿大大学
从学校了解起，再找到具体的本科入学项目。

[搜索中文名或英文名_______________] 8所学校
[全部] [BC] [ON] [QC] [AB]

[UBC]       [SFU]       [Waterloo]   [Toronto]
[McGill]    [UVic]      [Alberta]    [McMaster]
```

卡片：学校占位图或获准使用的校园图、省份标记、中英名称、城市、简述、查看学校链接。每张卡只做一个主要导航目标，收藏按钮独立可访问，不嵌套交互链接。

项目目录必须另有项目名、校区、学院与核验状态。只核验一般要求不能显示“完整规则已核验”。

## 5. 场景落地页

CASPer页面沿用首页双栏模板，并增加面包屑、场景特定标题和次级浏览链接。说明复用统一模板比每个场景单独设计更一致。

MaplePath学校详情套用：面包屑 → 校名/介绍 + 概览卡 → 校区与入学项目 → 申请路径说明 → 官方来源 → 使用档案模拟。

项目详情套用：项目名 + 所属校区/学院 → 课程条件 → 英语与材料 → 入学后分流 → 来源 → 登录模拟。不得把学校大宣传标题直接当具体专业要求。

## 6. 定价页的可借鉴之处

截图：03-pricing-desktop.png。原站三列等高套餐卡、突出中间卡边框、大字号价格、勾选权益、底部CTA对齐。这里只借鉴比较信息的层级，不复制套餐或价格。

可改为三张“探索—准备—行动”流程卡，或者三所目标项目的对比卡。对比应有清晰标签，不制造默认“推荐学校”。

## 7. MaplePath建议设计token

保持原站的排版与轻盈结构，但沿用MaplePath自己的森林绿品牌。统一执行本表，避免蓝绿两套主色混搭：

```css
:root {
  --canvas: #FAFAF7;
  --surface: #FFFFFF;
  --text: #141B17;
  --muted: #68736C;
  --primary: #254D40;
  --primary-hover: #1C3D32;
  --primary-soft: #EAF0E5;
  --border: #E3E7DF;
  --warning-text: #805B22;
  --warning-bg: #FFF4DE;
  --danger-text: #A03535;
  --radius-card: 20px;
  --radius-input: 12px;
  --radius-pill: 999px;
  --shadow-card: 0 16px 40px rgba(25, 45, 30, .07);
  --content-max: 1200px;
}
```

中文采用Noto Sans SC或系统中文无衬线，英文可选DM Sans；优先保证字体加载失败时布局稳定，离线demo不能依赖外部字体才正常显示。

建议字号：桌面hero 48—60px，中文注意换行；h2 28—36px；卡标题18—22px；正文16—18px；辅助12—14px。移动hero 32—38px。字号使用clamp，不用强制br造成窄屏溢出。

建议间距：8px基础节奏；页面横边距24—48px；区块上下64—96px；卡片24—32px；按钮高度44—48px。输入和按钮焦点可见。

## 8. 响应式与交互（本项目规范，非竞品实测）

- ≥1100px：首页双栏，学校卡四列。
- 768—1099px：首页适度收紧，学校卡两列。
- <768px：首页内容先于演示，学校卡单列；导航折叠。
- 360px可使用，标签允许换行或有明确横向滚动提示。
- 公共页面用顶部导航；学生区域可使用左侧导航，这是MaplePath的独立设计。
- 演示标签用button/tab语义、aria-selected与键盘交互；尊重prefers-reduced-motion，不强制自动切换。
- 筛选有选中态、结果计数、无结果提示、清除入口。
- 所有图片设尺寸/宽高比，避免加载跳动；截图不作为实际页面背景。
- 保持报告中的数字可解释，不为了视觉酷炫添加虚构仪表盘。

## 9. 第一轮视觉验收

1. 首页是清晰的公开产品入口，不把学生后台直接充当首页。
2. 首屏同时看见价值、行动按钮和报告输出示例。
3. 目录拥有搜索、筛选、计数与统一卡片。
4. 全站主色、圆角、字体、间距统一。
5. 免费学校与登录学生入口清楚。
6. 真实资料、示例、待核验状态容易辨认。
7. 公开页面可追溯来源，移动端无横向页面溢出。
8. 不复制MYLS品牌、照片、视频、营销数字或收费策略。
