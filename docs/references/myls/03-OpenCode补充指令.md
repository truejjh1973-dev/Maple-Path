# 追加到OpenCode第一轮任务的指令

你无需访问MYLS.ai。使用工作目录中的离线参考包：

`docs/references/myls/`

请先阅读README、01-参考功能框架.md、02-页面风格与实现规范.md，并查看同目录三张PNG截图（如果支持图像输入）。若不能读取图像，文字规范已足够实施，不因此停止。

本包来自真实公开页观察，区别于早期静态原型。功能边界以项目docs/01至04为准；参考包提供结构与视觉细化，不引入支付或面试录制需求。

关键要求：

1. 首页采用MYLS式清晰双栏：左侧价值与行动，右侧可切换报告预览。
2. 右侧五个视角为：兴趣画像、课程准备、关键差距、行动建议、情景对比。使用标注清楚的虚构案例，不调用真实AI也能演示。
3. 学校目录采用大标题、搜索、分类胶囊、结果计数、图片/占位图卡片；八所学校有可用详情入口。
4. 页面风格参考暖白、黑色大字、轻边框、宽留白、胶囊按钮；MaplePath主色统一使用森林绿#254D40，不能误以为MYLS原站是绿色。
5. 不复制原站文案、品牌图标、用户视频、图片、订阅策略和数字宣传。
6. 未观察到的登录后界面与后台，按MaplePath设计实施，不声称复刻MYLS内部系统。
7. 公共导航与学生导航区分；免费学校公开，学生个人功能有真实权限控制；demo模式有明确标签。
8. 不生成虚构录取概率、用户评价或成功案例。
9. 手机布局按本包响应式规范实现；原站移动布局未实测，不声称像素还原。
10. 完成后用本包视觉验收与项目功能测试共同检查，不以“看起来像”替代业务验证。

请把这些要求纳入原第一轮开发任务，继续执行工程化实现，不重新向用户索要MYLS网站内容。
